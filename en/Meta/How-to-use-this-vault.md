# How to use this vault

## Philosophy

This is **not** a general knowledge base.  
It is a focused collection of **fundamental principles** — the deep rules that govern systems.

## Recommended workflow

1. Start from the language README or Master Index.
2. Explore by domain.
3. When you open a principle note, read it in this order:
   - One-sentence definition
   - Full explanation
   - Feynman-style explanation
   - Metaphors & analogies
   - Concrete examples
   - Relationships section (this is where the real power of the system lives)
4. Use the cross-language links at the bottom if you want to compare explanations.

## Adding new principles

1. Copy the template from `_templates/Principle.md`
2. Place it in the correct domain folder
3. Fill every section
4. Update the relevant Indexes
5. Add reciprocal links in related principles

## Linking conventions

- Internal links use Obsidian wikilinks: `[[Principle Name]]`
- Cross-language links use relative Markdown links
- Tags are used for additional filtering
