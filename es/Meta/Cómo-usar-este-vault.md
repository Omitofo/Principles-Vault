# Cómo usar este vault

## Filosofía

Este **no** es una base de conocimiento general.  
Es una colección enfocada en **principios fundamentales** — las reglas profundas que gobiernan los sistemas.

## Flujo de trabajo recomendado

1. Empieza desde el README del idioma o el Índice Maestro.
2. Explora por dominio.
3. Cuando abras una nota de principio, léela en este orden:
   - Definición en una frase
   - Explicación completa
   - Explicación estilo Feynman
   - Metáforas y analogías
   - Ejemplos concretos
   - Sección de relaciones (aquí está el verdadero poder del sistema)
4. Usa los enlaces entre idiomas al final de la nota si quieres comparar explicaciones.

## Añadir nuevos principios

1. Copia la plantilla de `_templates/Principio.md`
2. Colócala en la carpeta de dominio correcta
3. Completa todas las secciones
4. Actualiza los Índices correspondientes
5. Añade enlaces recíprocos en los principios relacionados

## Convenciones de enlaces

- Los enlaces internos usan wikilinks de Obsidian: `[[Nombre del Principio]]`
- Los enlaces entre idiomas usan Markdown relativo
- Las etiquetas se usan para filtrado adicional
